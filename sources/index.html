The sources page is the trust layer for Veronica Hub. It lists the official and high-reliability records used to support the site's claims, including Capcom announcement material, the Steam store page and the official BIOHAZARD YouTube trailer.

The source policy is intentionally conservative. Official sources can confirm official facts. Store listings can confirm store-specific facts and platform presence. Rumors, leaks, placeholder retail listings and fan speculation can only be discussed as unconfirmed context, and they should not change claim status by themselves.

This page should be updated whenever a new source changes a claim. A source update should include what the source is used for, when it was checked, and which claims it affects. That keeps the site maintainable as the release window gets closer.
