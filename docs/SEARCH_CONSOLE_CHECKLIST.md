# Search Console Checklist

## Property

Use URL-prefix property:

https://residentevilveronica.com/

## Submit Sitemap

Submit:

https://residentevilveronica.com/sitemap.xml

## First 14-Day Checks

- Coverage: confirm core pages are discovered.
- Indexing: inspect homepage, release date, platforms, FAQ, media and sources.
- Performance: check queries that mention release date, platforms, trailer, PC requirements, demo and preorder.
- Enhancements: confirm FAQ rich result eligibility if available.

## Decision Rule

Do not expand P2 pages until the existing sitemap is submitted and core pages are at least discovered.
